---

## Reporting a Vulnerability

If you discover a security vulnerability or formula injection weakness within `fuzzymatch-finance`, please do not open a public issue.

Instead, please send an email directly to:

**Tri Kieu**  
Email: [trikieu293@gmail.com](mailto:trikieu293@gmail.com)

Please include:
- A description of the vulnerability and its potential impact.
- Reproducible proof-of-concept script, CSV, or Excel file.
- Affected components (e.g., `review_xlsx` export/import, CLI commands, rule synthesis).

You will receive an acknowledgment within 48 hours, and a coordinated fix will be released promptly.
